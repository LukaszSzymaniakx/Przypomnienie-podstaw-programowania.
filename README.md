# Przypomnienie-podstaw-programowania.

## Opis projektu
Projekt zawiera trzy podstawowe aplikacje konsolowe napisane w językach C# oraz Python:

1. **Kalkulator dwóch liczb**  
   - Dodawanie, odejmowanie, mnożenie, dzielenie
   - Obsługa błędu dzielenia przez zero

2. **Konwerter temperatur**  
   - Konwersja stopni Celsjusza na Fahrenheita
   - Konwersja stopni Fahrenheita na Celsjusza
   - Wzory: °F = °C × 1.8 + 32 oraz °C = (°F - 32) / 1.8

3. **Średnia ocen ucznia**  
   - Obliczanie średniej z podanych ocen (skala 1-6)
   - Sprawdzanie czy uczeń zdał (średnia ≥ 3.0)
   - Walidacja poprawności ocen
